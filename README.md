# Furlong — Tabletop Simulator assets

Build output for the Furlong prototype in Tabletop Simulator: card sheets, card backs, boards, mats
and tokens, and the saved game (`Furlong.json`) that points at them. Generated by an exporter; not
edited by hand. Placeholder art: public-domain paintings and partly AI-generated textures.

**To play:** download `Furlong.json` and put it in your Tabletop Simulator saves folder
(`Documents/My Games/Tabletop Simulator/Saves`), then in the game: Create > Singleplayer (or host),
Games > Save & Load > Furlong. The rules are in the Notebook (Quick start tab).
